SQL Server — Schema & ERD Showcase

Why a schema browser and not a live demo: SQL Server is a database engine, not something with a "live in the browser" form — there's nothing to deploy as a static site. Rather than fake a query console against data that isn't there, this page presents the real T-SQL DDL (schema.sql) for an IT asset management database (the same domain as the Java Spring Boot showcase elsewhere in this portfolio) as an interactive ER diagram and table browser.
