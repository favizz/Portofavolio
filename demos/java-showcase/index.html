Java / Spring Boot — Architecture Showcase

Why this page and not a live demo: Vercel doesn't run JVM services — there's no honest way to make a Spring Boot API "live" on a platform whose backend story is short-lived serverless functions in Node/Python/Go/Ruby, not a long-running JVM process. Rather than fake it, this is a real, compiling Spring Boot module (verified with mvn compile — 10 source files, BUILD SUCCESS) shown here as source + architecture. It's a compact re-implementation of the IT asset management API described in the PT Toyota Astra Motor "WMS" internship (asset movement/handover tracking, an append-only audit trail, JWT + RBAC).
