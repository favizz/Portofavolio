Go → WebAssembly: Telemetry Anomaly Detector

The detection logic below (main.go) is real Go, compiled with GOOS=js GOARCH=wasm and running directly in this tab — no server, no API call. It watches a simulated stream of smart-meter voltage/flow readings and flags anomalies using the same style of rolling, explainable rules as the Netflow IoT metering project described elsewhere in this portfolio (rolling z-score, sustained-spike windows, hard range checks), just reimplemented small enough to ship as a single WASM binary.
