C → WebAssembly: Stack-Based Expression Evaluator

evaluator.c is real C — hand-rolled stack ADTs over raw arrays (no <stack>, no libc containers), implementing the classic shunting-yard algorithm: tokenize → infix-to-postfix → postfix evaluation. Compiled with Emscripten to WebAssembly and run directly in this tab, the same kind of custom-ADT-from-scratch approach used in ITB's Algorithms & Data Structures coursework.
